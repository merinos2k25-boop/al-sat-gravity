# Ticaret Takip Uygulaması

Alış ve satışları takip etmek için mobil öncelikli web uygulaması.

## Özellikler

- 📱 Telefon, Tablet, Laptop, Diğer kategorileri
- 🔢 Hafıza seçeneği (8 GB - 1 TB)
- 💰 Alış fiyatı, satış fiyatı, masraf, kar/zarar
- 📦 Stok takibi (Stokta / Satıldı)
- 📊 Özet ve istatistikler
- 🔍 Arama ve filtreleme
- 🌙 Koyu / Açık tema
- 🎨 5 renk teması
- 🔤 3 yazı stili
- 📤 JSON dışa aktarma
- 📥 JSON içe aktarma
- 📱 PWA (telefona eklenebilir)

## Geliştirme

```bash
npm install
npm run dev
```

## Vercel'e Deploy

1. [vercel.com](https://vercel.com) hesabına giriş yap
2. "New Project" → "Import Git Repository"
3. `trade-tracker` klasörünü seç
4. Deploy!
